## /api/generate (cURL)
cloud@ubuntu-ollama:~$ curl http://localhost:11434/api/generate \
  -d '{
    "model": "asistente-ciberseguridad",
    "prompt": "¿Qué es ciberseguridad?",
    "stream": false
  }'
**Definición:** La ciberseguridad es la práctica de proteger la información y los sistemas informáticos contra amenazas, vulnerabilidades y ataques cibernéticos.

**Funcionamiento:** La ciberseguridad implica la implementación de medidas de seguridad para prevenir, detectar y responder a amenazas cibernéticas, como malware, phishing, ataques de fuerza bruta y ataques de estado. También implica la protección de la información confidencial y la privacidad de los usuarios.

**Ejemplo académico:** En un estudio sobre ciberseguridad, se analizaron los efectos de la implementación de un sistema de autenticación de dos factores en la reducción de ataques de phishing. Los resultados mostraron una reducción del 30% en el número de ataques de phishing después de implementar el sistema de autenticación.

**Consideraciones de seguridad:** Es fundamental implementar medidas de seguridad como la actualización de software, el uso de contraseñas seguras y la implementación de sistemas de detección de amenazas.

## /api/chat (cURL)
cloud@ubuntu-ollama:~$ curl http://localhost:11434/api/chat \
  -d '{
    "model": "asistente-ciberseguridad",
    "messages": [
      {"role":"user","content":"¿Qué es un firewall?"}
    ],
    "stream": false
  }'
**Definición:** Un firewall es una tecnología de seguridad que actúa como una barrera entre un sistema informático y la red externa, permitiendo o rechazando el tráfico de datos según ciertas reglas de seguridad.

**Funcionamiento:** El firewall monitorea el tráfico de datos entrante y saliente, comparándolo con una lista de permisos y denegaciones configurados. Si el tráfico cumple con las reglas, se permite el acceso. De lo contrario, se bloquea el tráfico.

**Ejemplo académico:** En un entorno de red, un firewall puede ser configurado para permitir el tráfico de datos de un servidor web a un equipo de red, pero bloquear el tráfico de datos de un equipo de red a un servidor web.

**Consideraciones de seguridad:** Es importante configurar un firewall de manera que permita solo el tráfico de datos necesario y bloquee el tráfico no autorizado para proteger la red contra ataques y vulnerabilidades.

Respuesta del segundo turno:
**Diferencia entre firewall y WAF:**

Un **firewall** es una tecnología de seguridad que protege una red o un sistema informático contra accesos no autorizados, bloqueando el tráfico de datos no permitido.

Un **WAF (Web Application Firewall)** es un tipo de firewall especializado que se centra en proteger aplicaciones web y servicios de Internet contra ataques y vulnerabilidades. Un WAF monitorea el tráfico de datos de las aplicaciones web y bloquea el tráfico no autorizado, protegiendo la seguridad y la estabilidad de las aplicaciones.

**Consideraciones de seguridad:** Un WAF es especialmente importante para proteger aplicaciones web que no tienen un firewall tradicional.

## Nota sobre el ejemplo de PowerShell de la guia
El bloque Invoke-RestMethod es sintaxis de PowerShell (anfitrion Windows). En este laboratorio Ollama
escucha solo en 127.0.0.1 dentro de la VM, por lo que desde el anfitrion no es alcanzable (ver Ejercicio 6).
Se deja asi a proposito: exponerlo requeriria OLLAMA_HOST=0.0.0.0 y aumenta la superficie de ataque.
